
# FocusDesk — To-Do App & Notes App

A responsive productivity application built with React.js for the Week 04 Minor Project.

## Project Overview

FocusDesk combines task management and note-taking into one application.

## Features

### To-Do App
- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks completed
- Filter All, Pending and Completed
- Add due dates
- Local Storage persistence

### Notes App
- Create notes
- Edit notes
- Delete notes
- Search notes
- Categorize notes
- Timestamps
- Local Storage persistence

## Technologies Used

- React.js
- JavaScript (ES6+)
- JSX
- Vite
- CSS
- Lucide React

## React Concepts

- Functional Components
- Props
- useState
- useEffect
- Event Handling
- Conditional Rendering
- List Rendering with map()
- Array filter()
- Arrow Functions
- Destructuring
- Spread Operator
- Local Storage

## Setup Instructions

1. Install Node.js.
2. Open this project in VS Code.
3. Open the terminal.
4. Run:

   npm install

5. Start the application:

   npm run dev

6. Open the local URL displayed in the terminal.
